# CodingAgents 06 — Minimising Context Bloat & Structured Session Memory

Companion deck for **Components 4 + 5** of Sebastian Raschka's *[Components of a Coding Agent](https://magazine.sebastianraschka.com/p/components-of-a-coding-agent)*. Covers the harness levers that keep a long coding session healthy: clipping tool outputs, transcript summarisation, recency weighting, deduplication, and the storage-time vs prompt-time distinction between working memory and the full transcript.

Includes a live context-budget visualizer that lets you see exactly how each compaction lever (clip size, compaction ratio, working-memory size) reshapes a turn's prompt — and when the budget overflows the model's window.
